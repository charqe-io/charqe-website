About

A software company building its own products.

Charqe is a software company based in Istanbul, Türkiye. We build mobile applications, web platforms and developer tools. Every product we ship is designed and developed in house.

What we do

Charqe is a software company whose revenue comes from the products it builds. We work in three areas:

  • Mobile applications. Everyday applications for iOS and Android. Our first product, GymA, is built around personal strength training tracking.
  • Web platforms. Product sites, administration panels and data interfaces — all designed to connect to the same underlying data layer.
  • Developer tools. Plugins and utilities that make daily engineering work easier. The doubleJ product family sits in this area.

How we work

When we start a product, the first artefact we produce is not a screen design but a stakeholder map: who is involved in this work, what information does each of them need, and who has not been accounted for yet?

The reason is practical. Software is usually written with a single user group in mind; when a second group arrives, the system cannot carry the weight and has to be rewritten. We assume from the start that the scope will grow.

In practice this becomes four principles:

  • A single source of truth. We never store the same record twice. Every party sees the same reality, limited to what their role permits.
  • Every surface speaks its own language. Showing the same data does not mean showing the same screen. Nobody should have to learn someone else’s interface.
  • Data responsibility comes first. Role-based access and data minimisation are the starting point of the architecture, not a layer added later.
  • Shipping is not the end. We measure, correct, and grow the system as its scope widens.

Technology

We use React Native and Expo on mobile, Astro and TypeScript on the web, and Kotlin with the IntelliJ Platform for developer tooling. For data and identity we prefer managed services, and user data is hosted in the European Union region.

Data and privacy

We do not sell user data and we do not share it with third parties for advertising. A request to delete an account means permanent deletion. See our Privacy Policy for details.
